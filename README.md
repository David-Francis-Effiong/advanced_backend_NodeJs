# Advanced Backend - Node.js Checkpoint

This repository contains the solutions for the Node.js checkpoint exercises.

## Tasks Covered:

1. **hello-world.js**
   - A simple program that prints "HELLO WORLD" to the console.

2. **server.js**
   - A basic HTTP server running on port 3000 that responds with `<h1>Hello Node!!!!</h1>\n`.

3. **file-system.js**
   - Demonstrates the use of the `fs` module to create a file (`welcome.txt`) and read from a file (`hello.txt`).

4. **password-generator.js**
   - Uses the `generate-password` npm package to generate a random password and logs it to the console.

5. **email-sender.js**
   - Uses the `nodemailer` npm package to send an email. (Requires updating the script with valid email credentials).

## Instructions to Run:
Ensure you have [Node.js](https://nodejs.org/) installed on your machine.

1. Clone the repository.
2. Run `npm install` to install the required dependencies (`generate-password` and `nodemailer`).
3. Run any of the scripts using `node <filename>`, for example:
   ```bash
   node hello-world.js
   ```
